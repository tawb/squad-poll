# Squad Poll

A Java console app where friends make a poll (like "where should we eat?"), vote on it, and get a winner. If the vote ends in a tie, a fun tiebreaker decides the winner.

This project is also built to practice and show all 22 classic design patterns.

## What it does

* Friends create a poll with a question and some options.
* Everyone votes.
* The group gets notified when the poll closes.
* If there is a tie, a tiebreaker step runs (like a random spin).

## Team

* Person A: builds the Poll Engine (handles creating and structuring polls).
* Person B: builds the Voting Logic (handles votes, notifications, and tiebreakers).
